# Twilio phone connection (MVP)

This adapter adds an inbound PSTN call path. Twilio supplies telephony and speech recognition via <Gather input="speech">; the receptionist response is generated by the self-hosted Ollama model. This keeps hosted LLM inference token charges at zero, but Twilio voice minutes and speech recognition may incur provider charges. This is turn-based speech, not full-duplex streaming audio.

## Configure
1. Start the stack and set a secure `APP_SECRET`, database password, and `TWILIO_AUTH_TOKEN` in `.env`.
2. Expose API through HTTPS (e.g. an ngrok HTTPS tunnel for local testing) and set `PUBLIC_BASE_URL` to that exact public origin.
3. In Twilio Console, configure your phone number's **A call comes in** webhook to:
   `POST https://YOUR_PUBLIC_HOST/voice/twilio/TENANT_UUID`
4. Set webhook method POST. Enable signature validation (default). Do not expose the service without TLS and a correct public URL.
5. Add business FAQs to the tenant knowledge base through the authenticated API. Test using a non-production number first.

## Routes
- `POST /voice/twilio/{tenant_id}` — inbound call greeting and speech gather.
- `POST /voice/twilio/{tenant_id}/turn/{call_id}` — transcript -> tenant-scoped retrieval -> local Ollama -> spoken reply -> next gather.
- `POST /voice/twilio/{tenant_id}/status` — provider status callback placeholder.

Twilio request signature validation uses the configured auth token and request URL. Reverse proxies must preserve/forward the external host and scheme correctly; if signature validation fails, fix proxy URL reconstruction rather than disabling validation in production.

## Known limitations
- Twilio's `Gather` speech recognition is provider-managed; local Whisper is not wired into live PSTN audio.
- No SIP trunk abstraction, streaming media/WebSocket audio, interruption/barge-in, local TTS, transfer-to-human, voicemail, recording, or DTMF menu yet.
- Status callback is not yet persisted or correlated to a call lifecycle.
- Configure call notices/consent, recording policy, emergency fallback, retention, and local telecom/legal requirements before launch.
